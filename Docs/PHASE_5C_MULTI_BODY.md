# Phase 5C — Multi-Body Scaffold

Second lunar outpost body without rewriting SpecialistBrain.

## Play Mode

| Control | Action |
|---------|--------|
| **F6** | Camera → Campus A (primary / party) |
| **F7** | Camera → Campus B (NE outpost) |

## What spawns

- **Campus A** — full showcase (unchanged)
- **Campus B** — smaller dome + HAB + PWR/Solar + OPS at `CampusBOrigin (54, 0, 48)`
- Stalkers around **both** plazas (default 2 + 2)
- Footprints reserved on both campuses
- Ground plane centered between A and B; grid 64²

## Notes

- Party still deploys at Campus A
- Mission combat stake counts **all** stalkers (A + B + waves)
- No per-body economy or brain changes yet
