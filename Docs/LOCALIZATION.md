# Localization

How Solar Majesty's text is translated, and how to add a language. Progress lives in
[LOCALIZATION_STATUS.md](LOCALIZATION_STATUS.md), generated by the extractor.

## For developers

Player-facing text goes through [`Loc`](../Assets/Scripts/Systems/Localization.cs). The English text
is the lookup key (gettext style), so code stays readable:

```csharp
GUI.Label(r, Loc.S("RESUME"));                                    // plain text
Notify(Loc.F("{0} built a {1}.", robotName, Loc.S("house")), 4f);  // values: numbered placeholders
Loc.T("tutorial.commons", "Raise Colony Commons");                  // id-keyed, for the rare non-sentence
```

Rules:

- **One sentence, one call.** Turn `$"..."` interpolations and `"a" + x + "b"` into a single
  `Loc.F` format, so a translator can reorder words. Keep format specifiers (`{0:N0}`).
- **Numbers** in `Loc.F` format invariantly (`1,250` everywhere); a German PC no longer turns
  `1.5 m` into `1,5 m` mid-English sentence.
- **Key hints:** `{ToolFlag}`-style key tokens (filled by `KeyHints.Fill`) must never be inside a
  `Loc.F` format (string.Format would throw). Translate first, then fill:
  `KeyHints.Fill(Loc.S("Press {ToolBuild}, then {BuildSlot1}."))`. Or pass the key as an F
  argument: `Loc.F("TALK  ·  {0}", KeyHint(GameAction.Confirm))`.
- **Do not translate:** `Debug.Log` text, ids and keys, resource/shader/object names, and the
  prompts sent to the local AI model.
- **Voice lines:** baked Overseer voice clips are found by a hash of the exact English line
  (`VoiceBank.LineKey`). The voice and any dedupe must keep receiving the English; translate only
  what is drawn.
- **Names that are also ids** (building and flag `displayName`, structure names, control names)
  stay English where they are stored; translate where they are drawn: `Loc.S(b.displayName)`,
  `ControlsList.NameText(action)`, `TechDef.DisplayNameText`. The extractor collects them by
  where they sit (see the catalog rules at the top of `Tools/loc/extract.py`).
- English text changes make the old translation stale; the extractor moves it to `obsolete` so a
  translator can reuse it.

After wrapping strings, run:

```bash
python Tools/loc/extract.py --report
```

It rewrites `Assets/Resources/Locale/en.json` (the source catalog), merges new strings into every
translation file without losing existing work, and refreshes the status report.

### Checking with the pseudo-language

With dev tools on (editor, development build or `-devtools`), Settings → Language offers
**Pseudo (QA)**, or start with `-language qps`. Every wrapped string becomes accented and about 35 %
longer: `Settings` → `[Šéţţîñĝš···]`. Anything still plain English on screen is not wrapped yet;
anything clipped will not fit German or French either.

## For translators

1. Start a table: `python Tools/loc/extract.py --new fr Français` (language code, then the
   language's own name; that name is what players see in Settings).
2. Fill in `Assets/Resources/Locale/fr.json`. Each entry:

   ```json
   {"en": "{0} EU a day", "key": "", "tr": "{0} EU par jour"}
   ```

   - Translate `en` into `tr`. Leave `tr` empty to fall back to English.
   - Keep every placeholder (`{0}`, `{1:N0}`) and every key token (`{ToolBuild}`, `{BountyUp}`)
     exactly; their order may change.
   - Keep `·` separators and UPPER-CASE where the English is upper-case (buttons and headers).
   - "EU" is the in-game currency, and Jex is the advisor's name: keep both.
   - Address the player as *vous*. Keep it terse: HUD rows are narrow.
   - French typography: a non-breaking space (U+00A0) before `:` `;` `!` `?` and inside « ».
   - Canon terms and the French in use:

     | English | Français |
     |---|---|
     | the Core (the player) | le Noyau |
     | charging station / CHARGERS chip | station de recharge / CHARGEURS |
     | battery (a building's purse) | batterie |
     | till | caisse |
     | Colony Commons / COMMONS | Communs de la colonie / COMMUNS |
     | bounty flag, pole | fanion de prime, mât |
     | bounty | prime |
     | workshop | atelier |
     | Fobot Yard / the yard | Chantier Fobot / le chantier |
     | courier, Haul | coursier, Haul |
     | squad | escouade |
     | den, den stalker | tanière, rôdeur des tanières |
     | Lodge (Horizon Lodge…) | Loge (Loge Horizon…) |
     | Colony Lifter (Mk II, Mk III) | Lanceur colonial (Mk II, Mk III) |
     | Landing Pad | Aire d'atterrissage |
     | Clear Threat / Defend Area | Éliminer la menace / Défendre la zone |
     | tempted / ignored | tenté / ignoré |
     | Low Battery (challenge) | Batterie faible |
     | EU, Jex, Anvil, Aegis, Horizon, Triage | unchanged |

3. Re-run the extractor whenever the game changes; it adds new strings and never deletes a translation.
4. Check it in game with `-language fr`.

## Fonts and scripts

The HUD uses Windows system fonts with a fallback chain (Segoe UI, Microsoft YaHei UI, Microsoft
JhengHei UI, Yu Gothic UI, Malgun Gothic, Nirmala UI, Leelawadee UI), so Cyrillic, Greek, Chinese,
Japanese, Korean, Indic and Thai text draws glyphs on Windows. Two limits before shipping such a
language:

- **Steam Deck / Proton** may not have those Windows fonts. Bundling an open font (for example Noto
  Sans CJK, SIL OFL) under `Assets/Resources/UI/Fonts/` is the reliable fix.
- **Right-to-left** scripts (Arabic, Hebrew) need shaping that IMGUI does not do; out of scope for now.

## Shipped languages

- **English** (source).
- **Français**: all 1,456 strings, translated with the glossary above and checked by a validator
  (placeholders, key tokens, line breaks, `·` separators, upper-case labels, EU and Jex kept). It
  has not had a native speaker's review yet: do one before listing French on the store page.

## What is not localized yet

- Strings listed in [LOCALIZATION_STATUS.md](LOCALIZATION_STATUS.md) under "unwrapped".
- Voice: baked Overseer voice and robot barks are English-only audio. Subtitles translate; the
  voice stays English.
- The optional local AI replies in English.
- Steam store page and achievement names are localized on the Steamworks site, not in the game.
