# Steam store and library art

Upload-ready graphics for the Steamworks store page and the Steam library, plus the Steam
client and community icons. Everything here is generated by
[make_store_art.py](../../Tools/steam/make_store_art.py) from real in-game renders: the scenes are
the game's own frames, and the only additions are a light colour grade, darkening gradients
behind the logo, and the logo. The capsules carry the game name as a logo and no other text
(no tagline, review quote, award or "Early Access" badge), as Steam's capsule rules require.

If the Library Assets page also asks for a 920×430 Library Header, the header capsule fits it.
The game's own icon (exe, taskbar, window) is not uploaded: it is built into the player from
`Assets/Art/Icon` (see below).

`source/` holds what the art was made from and review sheets that are **not** uploaded:
the key-art renders used (`*_keyart_*.jpg`), `preview_capsules.jpg` (every capsule at its real
size, plus the small capsule at search-result sizes), `preview_library_hero_with_logo.jpg`
(the hero with the logo roughly where the library puts it) and `icon_size_sheet.png`
(the icon at 16–256 px on light and dark).

## What they are made of

- **Key art:** the Mars colony late in the afternoon, from the release build. The store-shot
  harness (`-storeshots … -storeshotKeyart`, see `Assets/Scripts/Runtime/Platform/StoreShotHarness.cs`)
  builds a working colony, lets it run, then renders HUD-free frames straight into a large render
  texture (5760×3240, plus 4000×6000 portrait framings for the vertical capsules and a
  5760×1858 ultra-wide one for the hero), once in the tuned light and once with the day cycle held at a low afternoon sun
  (`*_golden`). Map labels and bounty beams are hidden for these frames. The page background is
  Europa, so the store page shows a second world.
- **Logo:** "SOLAR MAJESTY" set in Cinzel Black (SIL Open Font License 1.1,
  `Blender/fonts/Cinzel-Black.ttf`, the face of the 3D intro title) with ivory faces, copper rims
  and the crowned, ringed planet as the O, drawn in 2D to match the intro title.
- **Icon:** the same crowned, ringed planet on a dusk badge. 16–32 px versions are drawn
  separately (no crown, thicker ring) so they still read as a ringed planet.

## Rebuild

    # 1. Release build (the harness only runs in a player)
    & "C:\Program Files\Unity\Hub\Editor\6000.5.10f1\Editor\Unity.exe" -batchmode -quit -projectPath . `
      -executeMethod SolarMajesty.EditorTools.BuildCommands.BuildWindows -smBuildPath Builds\SteamRC
    # 2. Renders (keep the desktop unlocked and the game window in front; about 5 minutes a world)
    powershell -ExecutionPolicy Bypass -File Tools\qa\store_screenshots.ps1 -GameDir Builds\SteamRC\Windows -Keyart -Bodies Mars,Europa
    # 3. Compose (Python 3 with Pillow and numpy)
    python Tools/steam/make_store_art.py all --shots Builds/StoreShots

`make_store_art.py store` without new renders rebuilds the committed art exactly from the copies
in `source/`.
Which render feeds which slot, the crops and the logo placement are the `SLOTS`, `HERO` and
`BACKGROUND` tables at the top of the store section of the script.

## Before uploading

- Check each capsule in Steamworks' own preview (it shows the store, search and library sizes
  side by side).
- This is programmer art composed from game renders. A human artist pass on the key art and the
  logo is still worth doing before launch (see `Docs/RELEASE_CHECKLIST.md`).
